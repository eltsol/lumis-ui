# Lumis UI

Lumis UI is an accessible, themeable React design system built to connect
design decisions with dependable frontend implementation.

## What is included

- Semantic design tokens for color, spacing, typography, shape, elevation, and motion.
- Typed React components organized as atoms, molecules, organisms, and layout primitives.
- Light and dark themes through a shared `ThemeProvider`.
- Component stories, accessibility checks, interaction tests, and unit tests.

## Explore the system

Use the navigation to browse component documentation. Each component page
contains an interactive playground, API controls, variants, states, usage
guidance, and accessibility notes.

## Local development

```bash
npm install
npm run storybook
```

Storybook runs locally at `http://localhost:6006`.
